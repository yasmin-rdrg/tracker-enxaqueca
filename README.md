# Diário de Enxaqueca
 
Um aplicativo mobile desenvolvido em **Flutter + Dart** para monitoramento de episódios de enxaqueca. 
 
---
 
## Funcionalidades
 
- **Registrar episódios**: salvar data, intensidade da dor (1 a 10), gatilho e remédio utilizado.
- **Histórico**: visualizar todos os registros em ordem cronológica.
- **Excluir registros**: deslizar o item para a esquerda para apagar.
- **Banco de dados local**: todos os dados ficam salvos no próprio celular, sem necessidade de internet.

 
---

### Pré-requisitos
 
- [Flutter SDK](https://flutter.dev/docs/get-started/install) instalado
- [VS Code](https://code.visualstudio.com/) com extensões Flutter e Dart
- Dispositivo Android físico ou emulador
